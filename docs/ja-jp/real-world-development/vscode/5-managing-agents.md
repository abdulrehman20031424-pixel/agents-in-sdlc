GitHub Copilot をエージェントモードで使うと、コードベースを調べ、変更を提案し、ファイルを編集して、コマンドを実行します。VS Code の Copilot Chat では、ツールの呼び出しやファイルの編集をリアルタイムで確認できます。差分を確認して変更ごとに採用または取り消し、エディターを離れずに追加プロンプトで作業を調整できます。

この演習では、次の内容を学習します。

- アクセシビリティエージェントの作業をリアルタイムで監視します。
- 提案されたファイル編集をレビューして採用します。
- セッション中にエージェントへ指示し、ハイコントラストモードに加えてライトモードを追加します。

## シナリオ

[演習 4][previous-lesson]で使ったアクセシビリティカスタムエージェントが、ハイコントラストモードを実装しています。作業中にデザインチームから、既定のテーマが暗すぎると感じるユーザー向けにライトモードも必要だと依頼がありました。新しい会話を最初から始めず、既存のセッションに追加の作業を依頼します。

## Copilot の進捗を監視する

Copilot Chat ビューには、エージェントが調べたファイル、実行したコマンド、提案した編集が表示されます。各ファイルの編集は差分と **Keep** / **Undo** の操作とともに表示されます。

1. 演習 4 から Copilot Chat ビューに戻ります。
2. エージェントが動作する間、チャットをスクロールしてツールの呼び出しを確認します。ファイルの読み取りや編集、実行を求めるターミナルコマンドが表示されます。
3. エージェントがファイルの編集を提案したら、差分を確認します。
   - **Keep** を選択すると変更を採用します。
   - **Undo** を選択すると変更を取り消し、エージェントに再度作業させます。
4. チャット上部の **Files changed** を開き、セッション中に変更されたファイル全体を確認します。

> [!NOTE]
> ターミナルコマンドの実行などに許可が必要な場合、エージェントは一時停止して **Allow** を表示します。内容を確認し、許可してよいコマンドのみ承認してください。

5. エージェントがハイコントラストモードを実装し、変更内容の概要を表示するまで待ちます。

## ライトモードを追加するようエージェントに指示する

同じ会話を続けると、以前の作業で変更したコンポーネント、スタイル、local storage のパターンをエージェントが保持します。

1. Copilot Chat の入力欄に、次の追加プロンプトを送信します。

   ```plaintext
   Nice work! Now add a light-mode toggle alongside the high-contrast toggle. Light mode should follow the same pattern — persist via local storage and be accessible from the same area of the UI. The user should be able to enable high-contrast and light mode independently.
   ```

2. エージェントが既存の変更を確認し、ライトモードを追加する様子を見ます。
3. 新しい編集を1つずつ確認し、**Keep** または **Undo** を選択します。
4. 意図しないリファクタリングなどがあれば、チャット入力欄の横にある **Stop** で停止し、明確な追加プロンプトを送信します。

> [!TIP]
> 進行中のセッションへの追加指示は、最初からやり直すよりも速く修正できます。たとえば「CSS を簡潔にして、セレクターの重複ではなく CSS 変数を使う」「既存の設定パネルにライトモードを統合する」「両方の切り替えにキーボードショートカットを追加する」などと依頼します。

## 変更されたファイルをレビューする

コミットする前に、エージェントが変更したファイルを確認します。

1. VS Code で **Source Control** ビューを開きます。
2. 変更されたファイルの一覧を確認します。Astro コンポーネント、スタイル、関連テストなどが含まれます。
3. ファイルを開いて差分を確認します。ARIA 属性、キーボード操作、セマンティック HTML、local storage による設定の保持など、アクセシビリティパターンを確認します。
4. 問題がなければ **Source Control** パネルから変更をステージしてコミットします。次のレッスンで公開します。

## まとめと次のステップ

Copilot Chat のエージェントモードで進行中のセッションを監視し、各ファイルの編集をレビューして採用または却下し、コンテキストを保ったまま追加プロンプトを送信しました。次は、[アクセシビリティの作業を pull request として公開し、レビューします][next-lesson]。
